# Text Preprocessing & N-gram Analysis

A basic NLP project using **Python and NLTK** to explore text preprocessing and N-gram analysis.

## Topics Covered

- Sentence & Word Tokenization
- Lowercasing & Stopword Removal
- Stemming & Lemmatization
- Basic Spelling Correction
- Unigrams, Bigrams & Trigrams
- N-gram Frequency Analysis

## Tools

- Python
- NLTK
- Pandas

## Dataset

Uses the **NLTK Brown Corpus** for text processing and N-gram analysis. A 10,000-word subset is used for N-gram analysis.

## Purpose

This project is part of my **NLP learning journey**, focused on understanding fundamental text preprocessing and language modeling concepts.
